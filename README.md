# 🏋️ Real-Time AI Gym Trainer

A real-time AI-powered gym trainer that uses **computer vision and pose detection** to monitor exercise movements, count repetitions, and help users improve their workout form.

## 🚀 Features

* 🎥 Real-time camera-based exercise tracking
* 🤖 AI-powered pose detection
* 🔢 Automatic repetition counting
* 📐 Exercise form monitoring
* ⚡ Real-time workout feedback
* 🏋️ Multiple exercise support
* 💻 Simple and responsive user interface

## 🏋️ Supported Exercises

* 💪 Bicep Curls
* 🏋️ Shoulder Press
* 🦵 Squats
* 🤸 Push-Ups
* 🦵 Lunges

## 🧠 How It Works

```text
Camera
   ↓
Real-Time Video
   ↓
Pose Detection
   ↓
Body Landmark Detection
   ↓
Joint Angle Analysis
   ↓
Exercise Detection
   ↓
Rep Counting
   ↓
Real-Time Feedback
```

The system uses the camera to detect body landmarks and analyze joint movements. Based on these movements, it identifies exercises, counts repetitions, and provides real-time feedback about the user's form.

## 🎯 Project Objective

The goal of this project is to provide users with an **AI-based virtual gym trainer** that can monitor their exercises in real time without requiring a physical trainer.
